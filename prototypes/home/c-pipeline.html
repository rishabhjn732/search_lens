§2

How it works

1

Connect

Give the cluster address and login. The password stays in backend memory only.

2

Ask

Type text or a query. For example: running shoes.

3

Understand

Read the picture: tokens, matching words, each part of the score.

"It only reads. It never writes."Search Lens never creates, changes or deletes anything on your cluster. Your browser never talks to the cluster directly.
