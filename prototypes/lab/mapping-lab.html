Mapping lab

See how your index saves words, and how it finds them.

Paste an index definition. Search Lens draws every field, then tries 100 real shop searches against it, and shows which ones are found and why the others are not.

Prototype. The analysis here is a simplified copy that runs in this page. The real tool sends POST /_analyze to your cluster with the analyzer parts inside the request, so nothing is created on the cluster.

Where do I find my index definition?

In OpenSearch Dashboards, open Dev Tools and run GET /my-index. Copy the whole answer and paste it here. Search Lens understands that shape too.
